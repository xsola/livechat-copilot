# 数据处理说明

用户在扩展设置中选择模型地址、模型 ID 和可选 API Key。密钥保存在 Chrome 扩展的本地存储，可在设置中更新或清除。网络请求由扩展后台向已授权的地址发出。

「测试当前模型」使用当前填写的配置，向该模型发送一条内置示例弹幕和一张合成图片。测试可以在保存设置之前运行。

对某个直播间或网站启用翻译后，模型会接收翻译用的弹幕正文。用户在设置中开启自动图像复核后，扩展可在识别流程中本地裁图，向模型发送候选弹幕区裁图、简化 HTML 和少量正文。对比定位时会把最多三组候选区域合成一张图。可见、未聚焦且无草稿的候选输入框可能一起裁剪。模型服务按其自身的数据处理规则处理这些请求。

自动翻译在浏览器本地判断是否能跳过已是目标语言的弹幕。

侧栏读取直播输入框时，草稿留在浏览器中。点「翻译草稿」后，配置的模型接收草稿和目标语言。「问助手」的普通问题只发送问题和答案语言，需要当前直播上下文时才会附上近期弹幕样本。生成双语回复和推断房间语言也可能发送必要的房间基本信息及有限的弹幕样本。扩展使用导航权限枚举当前标签页中的同源 frame，以便分别找到弹幕列表和输入框。手动定位及房间语言偏好保存在本地，草稿、回复和分析结果仅留在会话中。填入或撤销由用户确认，消息由用户在直播网站发送。

启用社区规则订阅后，扩展从已授权的 GitHub Raw 地址读取规则索引。弹幕翻译和模型调用的本地统计按天汇总，保存最近 30 天的数据。设置页可以清空、预览和复制汇总。诊断摘要只含版本、次数、用量和耗时，由用户决定是否分享。
